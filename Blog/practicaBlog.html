Actualización de seguridad en servidores Debian

Publicado el 29 de octubre de 2026 por el Equipo de Sistemas.

Descripción del problema:

Los servidores que utilizan Debian pueden presentar vulnerabilidades si no se mantienen actualizados. Estas vulnerabilidades pueden permitir accesos no autorizados y comprometer la seguridad de los datos.

Solución aplicada:

Para mejorar la seguridad, los administradores deben instalar las actualizaciones disponibles y revisar periódicamente el estado del sistema.

Despliegue de aplicaciones mediante Docker

Publicado el 28 de octubre de 2026 por el Departamento de Infraestructura.

¿Qué es Docker?

Docker es una plataforma que permite ejecutar aplicaciones dentro de contenedores. Estos contenedores incluyen los elementos necesarios para que las aplicaciones funcionen de manera consistente en diferentes equipos.

Ventajas del despliegue con Docker

Utilizar Docker facilita la instalación y el mantenimiento de aplicaciones, ya que permite desplegar servicios de forma rápida y organizada.

Además, los contenedores permiten aprovechar mejor los recursos del servidor y simplifican la migración de aplicaciones entre distintos entornos.

Buenas prácticas para realizar copias de seguridad

Publicado el 27 de octubre de 2026 por el Equipo de Soporte Técnico.

Importancia de las copias de seguridad

Las copias de seguridad son fundamentales para proteger la información de una empresa frente a fallos de hardware, ataques informáticos o eliminaciones accidentales de archivos.

Disponer de una copia permite recuperar los datos y reducir las consecuencias de una pérdida de información.

Recomendaciones para realizar backups

Una de las estrategias más utilizadas es la regla 3-2-1, que consiste en mantener tres copias de los datos, almacenadas en dos tipos de soporte diferentes y con una copia fuera de la ubicación principal.

También es recomendable automatizar las copias de seguridad, protegerlas mediante cifrado y comprobar periódicamente que los archivos pueden recuperarse correctamente.
